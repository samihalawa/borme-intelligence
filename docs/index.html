03Primer uso

Empieza por una pregunta real.

Busca anuncios de una empresa en una provincia y distingue publicación, inscripción y acto descrito.
Límites de la herramienta
  • Los anuncios no representan un historial societario completo ni permiten inferir insolvencia o titulares reales.
  • La muestra tiene fecha de consulta y enlaces oficiales. No se han fabricado cifras ni actuaciones.
  • La disponibilidad de los sistemas oficiales puede variar; un fallo de origen nunca se presenta como cero resultados.
04Distribución

Un instrumento.

Plugin independiente de Claude Code, con flujo y adaptadores Python. No requiere cuenta adicional ni claves de API para consultar datos públicos.
